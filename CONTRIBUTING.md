# Contributing to Lyncost

Thank you for your interest in **Lyncost**!

## 🔒 Contributing Policy

To protect code ownership, legal clarity, and intellectual property integrity:

- **Pull Requests**: We **do not accept external pull requests**, code contributions, or patches. Any submitted pull requests will be respectfully closed without merging.
- **Bug Reports & Feedback**: We warmly welcome bug reports, user feedback, and feature suggestions! Please submit them using [GitHub Issues](https://github.com/leodarshantech/lyncost/issues).

## 🐛 Submitting an Issue

When opening an issue, please include:
1. Your Linux distribution and desktop environment (e.g., Arch Linux + GNOME Wayland).
2. Lyncost version (found in Settings -> About).
3. Steps to reproduce the issue.
4. Expected vs. actual behavior.

Thank you for understanding and helping keep Lyncost private, fast, and rock-solid!
